01 / OVERVIEW

Overview

As video world models enable longer, more realistic interactive experiences, maintaining a world consistent with its history becomes essential. WorldMemBench evaluates world memory across 260 cases, using controlled camera departures and multi-revisit trajectories to measure static retention and dynamic state evolution. Across nine representative models, strong static retention does not imply reliable dynamic evolution, while later revisits expose degradation beyond the first return.

02 / CONTRIBUTIONS

Contributions

01

A benchmark for world memory

We introduce WorldMemBench, a comprehensive benchmark for the structured evaluation of memory capabilities in video world models.

02

A diagnostic evaluation protocol

We develop a multi-revisit evaluation protocol to assess static and dynamic memory alongside camera controllability.

03

An empirical characterization of world memory

We evaluate nine video world models, revealing distinct memory profiles, cumulative degradation across revisits, and sensitivity to exploration direction and context access.
